# KGC 2026: key principles

Ten foundational principles for trustworthy AI with knowledge graphs, synthesized from the [Knowledge Graph Conference 2026](https://www.knowledgegraph.tech/) (May 4-8, 2026).

Live page: https://monideep2255.github.io/kgc-2026-key-principles/

## What this is

A single-page synthesis of ten foundational principles that emerged across 20 sessions at KGC 2026. Color-coded by theme (technology, organization, people) with an interconnection diagram showing how they relate.

## What this is not

This is not a transcript or a recap of individual sessions. Speaker quotes, slides, and session content belong to the speakers and the conference. This page contains only a high-level synthesis in my own words.
